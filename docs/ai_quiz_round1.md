# TraeCode 对拍第一轮记录（第4周）

范围：空安全、命名参数、整除。流程：先让 TraeCode 出题，我手写答案，再让它给参考答案和讲解，最后逐题复核。

## 第1题（空安全）

题目：

```dart
int? a;
void main() {
  print(a ?? 10);
}
```

- 我的答案：输出 10
- AI 答案：输出 10。a 是 null，`??` 左边为 null 时取右边。
- 复核：一致，实际运行输出 10。

## 第2题（空安全）

题目：

```dart
void main() {
  String? s;
  print(s?.length);
}
```

- 我的答案：输出 null
- AI 答案：输出 null。`?.` 在 s 为 null 时直接返回 null，不会报错。
- 复核：一致，实际运行输出 null。

## 第3题（命名参数）

题目：下面代码能不能编译通过？

```dart
void f({required int a, int b = 2}) {}
void main() {
  f(b: 3);
}
```

- 我的答案：不能。a 标了 required，调用时没传 a。
- AI 答案：不能，编译错误：缺少必填参数 a。
- 复核：一致，把代码粘到工程里 dart analyze 直接报缺少 a。

## 第4题（整除）

题目：

```dart
void main() {
  print(7 ~/ 2);
  print(7 / 2);
}
```

- 我的答案：3 和 3.5
- AI 答案：3 和 3.5。`~/` 是整除返回 int，`/` 永远返回 double。
- 复核：一致，运行结果相同。

## 第5题（空断言，有分歧）

题目：

```dart
void main() {
  int? x = 8;
  print(x! + 2);
}
```

- 我第一次写的答案：编译错误，x 是可空类型，不能直接做加法。
- AI 答案：输出 10。`x!` 已经断言 x 不是 null，断言后按 int 参与加法。
- 复核：我错了。自己运行后确实输出 10。原因是没分清 `x`（可空）和 `x!`（断言后的非空值）。以后看到 `!` 就当它把类型上的问号临时摘掉。

## 小结

5 题里 4 题一致，第5题我一开始答错，运行后按 AI 讲解改正。??、?.、! 三个符号的区别已在工程代码里各用了一遍验证。
