# lecture2

第4次作业：Dart 语言基础一（变量、类型、函数与控制流）

## 目录

- `dart_basics/`：课堂案例，纯 Dart 命令行程序
  - `bin/types_demo.dart`：变量、内置类型、字符串插值、空安全
  - `bin/func_demo.dart`：命名参数、默认值、箭头函数
  - `bin/flow_demo.dart`：成绩分级器、for-in 循环
  - `bin/practice.dart`：自主练习（空安全改写、实验报告生成器、分级器扩展）
- `docs/ai_quiz_round1.md`：TraeCode 对拍第一轮记录

## 运行

```bash
cd dart_basics
dart run
```
